# Telegram Shop Bot (реbranded)

Полнофункциональный магазин цифровых товаров на aiogram 3.

## Что умеет

- Каталоги и товары
- Оплата: RUB / СБП / USDT (CryptoBot) / Stars / через владельца
- Ручная проверка чеков
- Рулетка со скидками
- Редактор интерфейса (тексты + Premium Emoji)
- Админ-панель, рассылка, статистика
- Обязательная подписка на канал (опционально)

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# заполни .env
python bot.py
```

Основные настройки в `.env`:
- `BOT_TOKEN` — токен бота
- `ADMIN_ID` / `ADMIN_IDS` — твои Telegram ID
- `SHOP_NAME` — название магазина
- `SUPPORT_USERNAME` — юзернейм поддержки без @
- `REQUIRED_CHANNEL` — канал для подписки (или пусто)

База создастся автоматически при первом запуске (`shop.db`).

Старый `shop.db.bak` — бэкап базы из исходного архива (можно удалить).
